ORIGINAL BOLTZ-2 LIMITATION
---------------------------
Boltz-2 affinity input validation normally requires the affinity binder
chain to have entity type "ligand". RNA and DNA polymer chains therefore
cannot normally be designated as affinity binders.

The relevant parser was:
  src/boltz/data/parse/schema.py

The original validation rejected any binder for which:
  chain_name_to_entity_type[binder] != "ligand"

CODE ADAPTATION
---------------
Two parser changes were made.

1. Binder validation was expanded from ligand-only to:
     ligand, RNA, or DNA

   Modified logic:
     if chain_name_to_entity_type[binder] not in {"ligand", "rna", "dna"}:

2. Polymer chains parsed through parse_polymer() normally do not receive
   the affinity=True flag used by downstream affinity feature generation.

   For the selected RNA/DNA affinity binder, a ParsedChain is therefore
   created with:
     affinity=True
     affinity_mw=0.0

Molecular-weight correction was NOT enabled during inference. The
affinity_mw value is therefore only a placeholder for this unsupported
proof-of-concept workflow.

The Slurm scripts additionally set:
  PYTHONPATH=/projects/bentosprg6/linwx/repos/boltz/src

This guarantees inference imports the modified Boltz source tree instead
of an unmodified site-packages installation.

INTERPRETATION / LIMITATION
---------------------------
These affinity outputs demonstrate successful execution of the modified
Boltz-2 affinity pipeline for RNA and DNA aptamers.

They SHOULD NOT be interpreted as validated experimental aptamer binding
affinities.

Boltz-2 affinity modeling was developed for protein-small-molecule
complexes. RNA/DNA aptamers are outside the normal supported affinity
domain. The purpose of these runs is proof of technical adaptation and
execution, consistent with the Task 4 requirement that predictions do
not need to be correct.

TASK 4 CONCLUSION
-----------------
Boltz-2 was successfully adapted to allow nucleic-acid aptamer chains to
be specified as affinity binders.

The modified workflow was validated on:
  1. a protein-RNA aptamer complex
  2. a protein-DNA aptamer complex

Both completed structure prediction and affinity inference with zero
failed examples and generated affinity output JSON files.

No model retraining was performed.
